# Masterix LAN 0.4.0

This release changes Masterix LAN into a standalone compatibility add-on for the official e4mc mod.

### Important

Install both:

- Masterix LAN 0.4.0
- official e4mc 6.2.1+modern (or a compatible newer release)

Masterix LAN no longer bundles or modifies e4mc. It provides Android-native QUIC compatibility at runtime while leaving the installed e4mc JAR untouched.
