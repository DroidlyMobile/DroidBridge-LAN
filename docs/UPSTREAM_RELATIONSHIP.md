# Relationship to e4mc

Masterix LAN is an **independent compatibility add-on** for the official e4mc mod. It is not an official e4mc port and should not be presented as one.

## Packaging policy

Masterix LAN 0.4.0 does not bundle a modified e4mc JAR and does not ship `link.e4mc.*` classes. Users install e4mc separately as a required dependency.

Masterix LAN provides Android-specific native/runtime compatibility around the installed upstream mod. e4mc continues to own the public tunnel and Minecraft integration.

## Branding

Use Masterix LAN branding for this project. Credit and link e4mc clearly, but do not reuse the e4mc logo as the Masterix LAN project icon or imply upstream endorsement.

## Support routing

DroidBridge/Android compatibility issues should be reported to Masterix LAN. General e4mc behavior should be reproduced without Masterix LAN before being reported upstream.
