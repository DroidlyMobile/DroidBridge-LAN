# Privacy and network behavior

Masterix LAN itself adds no analytics or telemetry.

When the user opens a world publicly, the separately installed e4mc mod performs the network activity required for its public hosting feature. Masterix LAN provides Android compatibility for that upstream behavior; it does not operate or replace the e4mc service.

A public e4mc hostname should be treated like a server address: anyone who has the hostname can attempt to connect. Minecraft authentication and host/server permissions still apply.
